# Councours Robots 2026 - Gestion des utilisateurs et administration

Application web développée avec Laravel dans le cadre de la gestion d'un concours de robotique pour collégiens.

Cette partie du projet se concentre sur l'administration de la plateforme et la gestion des utilisateurs :

- Authentification et gestion des comptes utilisateurs ;
- Administration des utilisateurs ;
- Attribution des rôles ;
- Consultation et gestion des informations utilisateurs.

Projet réalisé dans le cadre d'ateliers professionnels effectués durant ma deuxième année d'études.
